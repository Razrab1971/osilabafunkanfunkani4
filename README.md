Чтобы собрать всея чудо нужно перейти в дирректорию: **.secrets**

`cd ./secrets` - команда чтобы перейти дирректорию

Создать три файла:

`touch db-password db-password2 TOKEN_bot` - команда создания трёх файлов

Написать в каждом несколько ASCII символов, которые образуют пароль для db,
записать токен для бота в файл TOKEN_bot, получаемого от BotFather, желательно следить за спецсимволами.
(Замечание: испольуйте тектовый редактор vim, например.)
